# MEDORA application source

Đọc [README chính](../README.md) để cài đặt, build, seed demo, kiểm thử và vận hành.

- backend/: Java 21 / Spring Boot / PostgreSQL / Flyway.
- frontend/: Next.js / React / TypeScript.
- scripts/: cấu hình, dữ liệu demo và kiểm tra HTTP.
- compose.yaml: chạy toàn bộ bằng Linux containers.

Tài liệu ứng dụng ở ../docs/; báo cáo/UML môn học ở ../doc/.
